# Bank Analysis Project
# Overview

This project focuses on analyzing banking data to uncover insights, visualize trends, and support decision-making. The main objectives of the project are:

Use SQL to query, filter, and aggregate data for analysis.

Perform Exploratory Data Analysis (EDA) to understand the dataset and extract key patterns.

Build an interactive dashboard using Power BI for effective visualization of banking metrics.

The project demonstrates a combination of data analytics, visualization, and database querying skills applied to real-world banking datasets.

# Features

# SQL Queries:

Extracting relevant data from tables.
Filtering, grouping, and aggregating data for analysis.
Supporting dashboard visuals with structured queries.

# Exploratory Data Analysis (EDA):

Handling missing values, duplicates, and outliers.
Summary statistics, correlations, and distributions.
Identification of trends and patterns in customer behavior and bank performance.

# Power BI Dashboard:

Interactive visualizations including bar charts, line charts, and pie charts.
Key metrics: customer demographics, account balances, transaction trends, and revenue distribution.


# Tools and Technologies

Excel / CSV — for storing and importing datasets.

SQL (MySQL / PostgreSQL / SQLite) — for data extraction, filtering, and aggregation.

Python (Pandas, NumPy, Matplotlib, Seaborn) — for EDA and data preprocessing.

Power BI — for creating interactive dashboards and data visualization.

# How to Use

SQL Queries: Use the provided SQL scripts or queries to extract and aggregate data for custom analysis.

EDA: Open EDA.ipynb in Jupyter Notebook to explore the data, visualize distributions, and perform data cleaning.

Power BI Dashboard: Open Bank_dash.pbix to interact with the dashboard and explore key metrics.
